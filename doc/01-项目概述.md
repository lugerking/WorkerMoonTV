# WorkerMoonTV 项目概述

> 本文档为 WorkerMoonTV 项目的整体分析文档之一，面向开发者与运维人员。

## 1. 项目简介

**WorkerMoonTV** 是一个开箱即用的**影视聚合播放器**，是 MoonTV 的 **Cloudflare Workers 版本**。它本身不存储任何视频资源，而是通过聚合多个第三方「苹果 CMS V10」资源站的 API，实现**多源搜索、在线播放、收藏同步、播放记录**等功能，并借助豆瓣接口提供影视榜单与分类浏览。

项目基于 **Next.js 14（App Router）+ TypeScript + Tailwind CSS** 构建，通过 [OpenNext Cloudflare](https://opennext.js.org/cloudflare) 适配器打包为 **Cloudflare Workers** 应用，数据默认存储在 **Cloudflare D1**，同时保留 Redis / Upstash / 浏览器本地存储支持。

- package 名称：`worker-moontv`，版本 `0.1.0`
- 运行形态：Cloudflare Worker（`.open-next/worker.js`）+ 静态资源（`ASSETS` 绑定）
- 开源协议：MIT

## 2. 核心功能特性

| 功能 | 说明 |
| --- | --- |
| 🔍 多源聚合搜索 | 内置 20 个资源站点（`config.json` 的 `api_site`），一次搜索并行返回全源结果 |
| 📄 丰富详情页 | 展示剧集列表、演员、年份、简介等完整信息 |
| ▶️ 在线播放 | 集成 **ArtPlayer + HLS.js**，支持 m3u8 播放、清晰度切换、播放进度记忆 |
| ❤️ 收藏 + 继续观看 | 收藏夹与播放记录，支持 D1/Redis/Upstash 多端同步 |
| 📱 PWA | 通过 `next-pwa` 实现离线缓存、安装到桌面/主屏 |
| 🌗 响应式布局 | 桌面侧边栏 + 移动端底部导航，深色模式 |
| 👿 智能去广告 | 自动跳过视频中的切片广告（实验性） |
| 🎬 豆瓣浏览 | 首页热门电影/剧集/综艺，豆瓣分类浏览（电影/电视剧/综艺/自定义分类） |
| 🛠 管理后台 | `/admin` 运行时动态管理站点、视频源、分类、用户（仅非 localstorage；D1 下同样可编辑） |

## 3. 技术栈

| 分类 | 主要依赖 |
| --- | --- |
| 前端框架 | Next.js 14.2（App Router，`output: 'standalone'`） |
| 语言 | TypeScript 4.9 |
| 部署适配 | `@opennextjs/cloudflare` 1.15.0 + `wrangler` 4 |
| UI & 样式 | Tailwind CSS 3、lucide-react、@heroicons/react、sweetalert2 |
| 播放器 | ArtPlayer 5 + HLS.js 1.6（另引入 vidstack） |
| 状态/交互 | React 18、next-themes、framer-motion、swiper、@dnd-kit（拖拽排序） |
| 存储 | Cloudflare D1（默认）、redis（node-redis）、@upstash/redis、localStorage |
| 边缘运行时 | Cloudflare Workers（`nodejs_compat` 兼容标志） |

## 4. 目录结构总览

```
WorkerMoonTV/
├── config.json              # 站点配置：缓存时间、资源站 api_site、自定义分类（构建期读入）
├── next.config.js           # Next.js 配置（standalone、PWA、SVG、webpack fallback、OpenNext dev）
├── open-next.config.ts      # OpenNext Cloudflare 适配器配置
├── wrangler.jsonc           # Workers 部署配置：入口、资源、D1 绑定、KV 绑定、变量、路由
├── tailwind.config.ts       # Tailwind 主题配置
├── tsconfig.json            # TypeScript 配置（路径别名 @/*；排除 open-next.config.ts）
├── postcss.config.js        # PostCSS（Tailwind + autoprefixer）
├── scripts/                 # 构建期脚本
│   ├── convert-config.js    # 将 config.json 转为 src/lib/runtime.ts
│   └── generate-manifest.js # 生成 PWA manifest.json
├── public/                  # 静态资源（logo、截图、图标、manifest、sw.js）
└── src/
    ├── middleware.ts        # 鉴权中间件（登录态校验、签名验证、重定向）
    ├── app/                 # App Router 页面与 API 路由
    │   ├── layout.tsx        # 根布局：读取 D1 配置、注入 window.RUNTIME_CONFIG、主题
    │   ├── page.tsx          # 首页：热门电影/剧集/综艺、收藏夹、继续观看
    │   ├── play/             # 播放页
    │   ├── search/           # 搜索页
    │   ├── douban/           # 豆瓣分类浏览页
    │   ├── login/            # 登录 / 注册页
    │   ├── admin/            # 管理后台
    │   ├── warning/          # 未设置密码时的警告页
    │   └── api/              # 后端接口（Node.js Runtime，经 OpenNext 运行于 Workers）
    ├── components/          # 通用组件
    └── lib/                 # 核心逻辑：配置、存储、搜索、豆瓣、鉴权、类型
```

> 与上游 MoonTV 相比，本版本已精简掉 Docker（`Dockerfile`/`start.js`）、CI（`.github/`）、测试（`jest.*`）、代码规范（ESLint/Prettier/commitlint）等非运行必需文件，并新增 `open-next.config.ts` 与 `wrangler.jsonc`。

## 5. 存储方式

通过环境变量 `NEXT_PUBLIC_STORAGE_TYPE` 切换四种存储后端：

| 存储类型 | 值 | 说明 |
| --- | --- | --- |
| 浏览器本地存储 | `localstorage`（默认） | 数据存于浏览器，不支持注册与管理后台 |
| Cloudflare D1 | `d1` | 需绑定名为 `DB` 的 D1 数据库（本项目生产配置） |
| 原生 Redis | `redis` | 需 `REDIS_URL`（Workers 下需 TCP 支持，一般不使用） |
| Upstash Redis | `upstash` | 需 `UPSTASH_URL` + `UPSTASH_TOKEN` |

> 除 localstorage 外，其他存储方式均支持**多账户、记录同步和管理后台**。

## 6. 关键环境变量与绑定

环境变量分为三类：**构建期内联变量**、**运行时明文变量（`wrangler.jsonc` 的 `vars`）**、**密钥（Secret）**。

| 变量 / 绑定 | 类型 | 说明 | 默认值 |
| --- | --- | --- | --- |
| `NEXT_PUBLIC_STORAGE_TYPE` | 构建期内联 + 运行时 | 存储方式 | localstorage |
| `NEXT_PUBLIC_ENABLE_REGISTER` | 构建期内联 + 运行时 | 是否开放注册 | false |
| `NEXT_PUBLIC_SEARCH_MAX_PAGE` | 构建期内联 | 搜索可拉取最大页数 | 5 |
| `NEXT_PUBLIC_IMAGE_PROXY` | 构建期内联 | 图片代理前缀 | 空 |
| `NEXT_PUBLIC_DOUBAN_PROXY` | 构建期内联 | 豆瓣数据代理前缀 | 空 |
| `NEXT_PUBLIC_DISABLE_YELLOW_FILTER` | 构建期内联 | 关闭色情内容过滤 | false |
| `USERNAME` | 运行时明文 | 站长（owner）账号 | 空 |
| `PASSWORD` | 运行时 **Secret** | 站长密码；同时作为登录 Cookie 的签名密钥 | 空 |
| `SITE_NAME` / `ANNOUNCEMENT` | 运行时明文 | 站点名称 / 公告（DB 未设置时的默认值） | MoonTV / 见 `layout.tsx` |
| `REDIS_URL` / `UPSTASH_URL` / `UPSTASH_TOKEN` | 运行时明文 | 对应存储的连接信息 | 空 |
| `DB`（D1 绑定） | 绑定 | D1 数据库（用户数据），**绑定名必须为 `DB`** | — |
| `CONFIG_KV`（KV 绑定） | 绑定 | 管理员配置存储（按字段分为 `admin_config:site` / `:sources` / `:categories` 三个分片），**绑定名必须为 `CONFIG_KV`** | — |

> ⚠️ `NEXT_PUBLIC_*` 会在构建时被内联进产物，因此**构建时也必须设置**同名环境变量。
>
> 本项目的配置优先级为 **数据库 > 环境变量/config.json**：配置存储（Workers KV 的 `admin_config`）中已有值时以配置存储为准，环境变量与 `config.json` 仅作为「初始化默认值」。详见 [02-架构与数据流](./02-架构与数据流.md#2-配置体系与优先级)。
