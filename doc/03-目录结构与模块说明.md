# 目录结构与模块说明

本文档逐层说明 WorkerMoonTV 的目录、文件及其职责。

## 1. 根目录

| 文件 | 说明 |
| --- | --- |
| `config.json` | 站点配置文件：`cache_time`、`api_site`（20 个资源站）、`custom_category`（可选，自定义分类） |
| `next.config.js` | Next.js 配置：`output: 'standalone'`、`initOpenNextCloudflareForDev()`、图片域名放开、SVG 转组件、webpack fallback、`next-pwa` |
| `open-next.config.ts` | OpenNext Cloudflare 适配器配置（`defineCloudflareConfig()`） |
| `wrangler.jsonc` | Workers 部署配置：入口 `.open-next/worker.js`、`assets` 绑定 `ASSETS`、`nodejs_compat`、D1 绑定 `DB`、`vars`、自定义域路由 |
| `tailwind.config.ts` | Tailwind 主题（深色模式、字体、动画、插件 `@tailwindcss/forms`） |
| `tsconfig.json` | TS 配置，路径别名 `@/*` → `src/*`；`exclude` 含 `open-next.config.ts` |
| `postcss.config.js` | PostCSS（Tailwind + autoprefixer） |
| `next-env.d.ts` | Next 生成的类型声明 |
| `package.json` / `package-lock.json` | 依赖与脚本 |
| `.gitignore` | Git 忽略规则（含 `.open-next`、`.wrangler`） |
| `LICENSE` | MIT 协议 |
| `README.md` | 项目说明 |

> 与上游 MoonTV 相比，此处已移除非运行必需文件：`Dockerfile`、`start.js`、`proxy.worker.js`、`vercel.json`、`D1初始化.md`、`VERSION.txt`、`jest.config.js`、`jest.setup.js`、`.eslintrc.js`、`.prettierrc.js`、`commitlint.config.js`、`.github/`、`.husky/`、`.vscode/` 等。

## 2. scripts/（构建期脚本）

| 文件 | 说明 |
| --- | --- |
| `convert-config.js` | 读取根目录 `config.json`，生成 `src/lib/runtime.ts`（编译期运行时配置），供 Workers/Serverless 环境使用 |
| `generate-manifest.js` | 依据 `SITE_NAME` 生成 `public/manifest.json`（PWA 清单） |

> `package.json` 的 `dev`/`build`/`build:worker` 脚本会在构建前依次执行 `gen:runtime` 与 `gen:manifest`。

## 3. src/ 顶层

| 文件 | 说明 |
| --- | --- |
| `src/middleware.ts` | Next.js 中间件：鉴权拦截、签名校验、登录/警告重定向、API 401 |
| `src/app/globals.css` | 全局样式（含 Tailwind 指令、播放器样式覆写、View Transitions） |
| `src/styles/` | 备用样式（`colors.css` 调色板、`globals.css` 备用全局样式） |

## 4. src/app/（App Router 页面）

> 根布局声明 `export const dynamic = 'force-dynamic'`，所有页面运行时渲染。

| 路径 | 文件 | 职责 |
| --- | --- | --- |
| 根布局 | `app/layout.tsx` | 读取 D1 配置动态生成标题；注入 `window.RUNTIME_CONFIG`；主题/站点 Provider、全局错误提示 |
| `/` | `app/page.tsx` | 首页：Tab 切换「首页 / 收藏夹」；继续观看、热门电影/剧集/综艺；公告弹窗 |
| `/douban` | `app/douban/page.tsx` | 豆瓣分类浏览：电影/电视剧/综艺/自定义分类，无限滚动加载 |
| `/search` | `app/search/page.tsx` | 聚合搜索：搜索框、搜索历史、按源分组、聚合开关 |
| `/play` | `app/play/page.tsx` | 播放页：ArtPlayer + HLS 播放、选集、换源测速、收藏、跳过片头片尾、去广告 |
| `/login` | `app/login/page.tsx` | 登录 / 注册，展示版本与更新状态 |
| `/admin` | `app/admin/page.tsx` | 管理后台：站点配置 / 用户配置 / 视频源 / 分类配置四个 Tab |
| `/warning` | `app/warning/page.tsx` | 未设置 `PASSWORD` 时的安全警告页 |

## 5. src/app/api/（后端接口）

> 全部为 Node.js Runtime（`export const runtime = 'nodejs'`），经 OpenNext 运行于 Workers。除白名单外均经中间件鉴权。

| 接口 | 方法 | 职责 |
| --- | --- | --- |
| `api/search/route.ts` | GET | 聚合搜索所有启用源 |
| `api/search/one/route.ts` | GET | 单源精确搜索（OrionTV 兼容） |
| `api/search/resources/route.ts` | GET | 返回可用源列表（OrionTV 兼容） |
| `api/detail/route.ts` | GET | 获取指定源指定 id 的详情与播放地址 |
| `api/douban/route.ts` | GET | 豆瓣榜单（支持 `top250` HTML 解析） |
| `api/douban/categories/route.ts` | GET | 豆瓣分类（rexxar API） |
| `api/image-proxy/route.ts` | GET | 图片代理（规避防盗链） |
| `api/login/route.ts` | POST | 登录，签发 `auth` Cookie |
| `api/register/route.ts` | POST | 注册（非 localstorage 且开放注册） |
| `api/logout/route.ts` | POST | 清除 `auth` Cookie |
| `api/change-password/route.ts` | POST | 用户修改密码 |
| `api/server-config/route.ts` | GET | 返回站点名与存储类型（白名单免鉴权） |
| `api/favorites/route.ts` | GET/POST/DELETE | 收藏的读取/保存/删除/清空 |
| `api/playrecords/route.ts` | GET/POST/DELETE | 播放记录的读取/保存/删除/清空 |
| `api/searchhistory/route.ts` | GET/POST/DELETE | 搜索历史的读取/追加/删除 |
| `api/skipconfigs/route.ts` | GET/POST/DELETE | 跳过片头片尾配置的读写 |
| `api/admin/config/route.ts` | GET | 读取管理员配置（owner/admin） |
| `api/admin/site/route.ts` | POST | 更新站点设置 |
| `api/admin/source/route.ts` | POST | 视频源增删启停/排序 |
| `api/admin/category/route.ts` | POST | 自定义分类增删启停/排序 |
| `api/admin/user/route.ts` | POST | 用户管理（增删/封禁/设管理员/改密） |
| `api/admin/reset/route.ts` | GET | 站长重置配置 |
| `api/cron/route.ts` | GET | 定时任务入口（白名单免鉴权） |

## 6. src/lib/（核心逻辑）

| 文件 | 说明 |
| --- | --- |
| `lib/config.ts` | 配置加载与合并：`getConfig()`（**数据库优先**，环境变量/config.json 兜底）、`resetConfig()`、`getCacheTime()`、`getAvailableApiSites()`、`API_CONFIG`（苹果 CMS 接口路径与请求头） |
| `lib/admin.types.ts` | `AdminConfig`、`AdminConfigResult` 类型定义 |
| `lib/types.ts` | `PlayRecord`、`Favorite`、`SkipConfig`、`IStorage`、`SearchResult`、`DoubanItem`、`DoubanResult` |
| `lib/db.ts` | 存储工厂与 `DbManager`/`db` 实例，`getStorage()`、`generateStorageKey()` |
| `lib/d1.db.ts` | Cloudflare D1 存储实现 `D1Storage`（用户数据；经全局符号获取 `DB` 绑定） |
| `lib/kv.db.ts` | 管理员配置存储（Workers KV；经全局符号获取 `CONFIG_KV` 绑定；按顶层字段分为 3 个分片，支持局部写入与旧数据自动迁移） |
| `lib/users.ts` | 用户数据访问辅助（从存储层读取用户名/角色/封禁并归一化站长；用户唯一数据源为 `users` 表等用户存储） |
| `lib/redis.db.ts` | 原生 Redis 存储实现 `RedisStorage` |
| `lib/upstash.db.ts` | Upstash Redis 存储实现 `UpstashRedisStorage` |
| `lib/db.client.ts` | 客户端数据层：localStorage 读写 + 数据库模式的混合缓存与乐观更新、事件订阅 |
| `lib/auth.ts` | 服务端/浏览器端读取 `auth` Cookie |
| `lib/downstream.ts` | 下游资源站抓取：`searchFromApi()`、`getDetailFromApi()`、剧集解析（含特殊源 HTML 解析） |
| `lib/fetchVideoDetail.ts` | `fetchVideoDetail()`：精确搜索命中，否则退回 `getDetailFromApi()` |
| `lib/douban.client.ts` | 豆瓣接口客户端封装：`getDoubanCategories()`、`getDoubanList()`、`shouldUseDoubanClient()` |
| `lib/utils.ts` | 工具函数：图片/豆瓣代理 URL 处理、HTML 清洗、m3u8 清晰度与测速 |
| `lib/yellow.ts` | 色情内容关键词列表 `yellowWords`（用于过滤） |
| `lib/version.ts` | 版本常量与更新检查 `checkForUpdates()`（对比 GitHub 远端 `VERSION.txt`） |
| `lib/runtime.ts` | 构建期由 `scripts/convert-config.js` 生成（自动生成，勿手改） |
