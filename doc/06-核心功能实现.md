# 核心功能实现

本文档说明 WorkerMoonTV 各核心功能的实现思路与关键代码位置。

## 1. 聚合搜索

- **入口**：`src/app/search/page.tsx`（搜索页）→ `GET /api/search`。
- **核心逻辑**：`src/lib/downstream.ts` 的 `searchFromApi(site, query)`：
  - 以 `config.json` 中该源的 `api` 为基址，拼接 `API_CONFIG.search.path`（`?ac=videolist&wd=`），携带固定 UA / Accept 头。
  - 支持**多页抓取**，页数上限受 `SearchDownstreamMaxPage`（默认 5）限制。
  - 解析返回 JSON 的 `list`，映射为统一的 `SearchResult[]`。
- **并行聚合**：`/api/search` 对所有启用源（`getAvailableApiSites()`）并行调用，扁平化返回。
- **内容过滤**：若未开启「禁用黄色过滤器」，按 `type_name` 过滤 `lib/yellow.ts` 中的 `yellowWords`。
- **前端体验**：搜索页支持**聚合视图**（按 `title+year+type` 分组，同片多源合一）与按源分组视图切换；搜索历史记录在 `/api/searchhistory`（≤20 条）。
- **OrionTV 兼容**：另提供 `/api/search/one`（单源精确搜索）与 `/api/search/resources`（源列表）。

## 2. 在线播放（ArtPlayer + HLS）

- **入口**：`src/app/play/page.tsx`。
- **播放器**：ArtPlayer 5 + hls.js 1.6，播放 `episodes` 中的 m3u8 地址；支持清晰度、倍速、全屏等。
- **详情获取**：`GET /api/detail?source&id` → `getDetailFromApi()` 取剧集列表；`fetchVideoDetail()` 会先做精确搜索命中，否则退回详情接口。
- **多源优选**：播放页可跨源聚合搜索并进行**测速**，评分 = 分辨率 40% + 速度 40% + 延迟 20%（`lib/utils.ts` 的 `getVideoResolutionFromM3u8`），据此推荐最佳源。
- **选集/换源**：`src/components/EpisodeSelector.tsx` 提供分页选集与换源 Tab（展示各源测速信息）。
- **进度记忆**：播放进度写入播放记录（见第 5 节），支持「继续观看」与断点续播。

## 3. 去广告

- 实验性功能：解析 m3u8 时过滤 `#EXT-X-DISCONTINUITY` 等切片广告标记（在播放页对播放列表做处理）。
- 属于启发式方案，对某些源有效。

## 4. 跳过片头片尾

- **配置存储**：`skip_configs`（`/api/skipconfigs` 读写），键为 `source+id`，值 `{ enable, intro_time, outro_time }`。
- **使用**：播放页根据当前 `source`+`id` 读取配置，播放到 `intro_time` 时自动跳过片头，接近片尾 `outro_time` 时提示/跳过片尾。

## 5. 播放记录与收藏

- **播放记录**：`/api/playrecords`（`play_records` 表）；保存时补全 `save_time`，用于「继续观看」排序。
- **收藏**：`/api/favorites`（`favorites` 表）；卡片心形按钮即时反馈。
- **继续观看**：`src/components/ContinueWatching.tsx` 读取播放记录，按 `save_time` 倒序渲染，支持清空。
- **多端同步**：数据库模式（D1/Redis/Upstash）下记录随账号同步；localstorage 模式仅本机。

## 6. 豆瓣浏览

- **首页榜单**：`src/lib/douban.client.ts` 的 `getDoubanList()`；`getDoubanCategories()` 取分类。
- **代理策略**：`shouldUseDoubanClient()` 依据 `NEXT_PUBLIC_DOUBAN_PROXY` 决定走「服务端 API」还是「浏览器端代理」；图片经 `NEXT_PUBLIC_IMAGE_PROXY` / `/api/image-proxy` 处理以绕过防盗链。
- **榜单接口**：`GET /api/douban`（`tag=top250` 走 HTML 正则解析）；分类接口 `GET /api/douban/categories`（rexxar `recent_hot`）。
- **自定义分类**：来自 `AdminConfig.CustomCategories`（或 `config.json` 的 `custom_category`），在 `DoubanCustomSelector` 中展示。

## 7. 客户端缓存与数据订阅

- **localstorage 模式**：`src/lib/db.client.ts` 直接读写浏览器 `localStorage`。
- **数据库模式**：`HybridCacheManager` 本地缓存（约 1 小时过期）+ **乐观更新 + 后台接口同步**；请求 401 自动跳登录。
- **跨组件刷新**：`subscribeToDataUpdates(event, callback)` 事件订阅，收藏/记录变更后各页面即时更新。

## 8. 管理后台

- **入口**：`src/app/admin/page.tsx`（四个可折叠 Tab：站点配置 / 用户配置 / 视频源配置 / 分类配置）。
- **数据流**：`GET /api/admin/config` 拉取 `AdminConfig`；各 Tab 通过 `POST /api/admin/{site,user,source,category}` 修改后回写数据库。
- **权限**：`owner`（站长，用户名等于 `USERNAME`）与 `admin`；敏感操作分级限制。
- **可编辑范围（本版本已放开）**：
  - 站点配置：站点名称、公告、图片/豆瓣代理、禁用黄滤、注册开关 —— 均可修改并即时生效（数据库为权威来源）。
  - 视频源：可新增自定义源、启停、排序；`from: 'config'`（来自 `config.json`）的源不可删除，但可改属性、启停、排序。
  - 自定义分类：可新增/启停/删除/排序。
- **重置**：`GET /api/admin/reset` 可将配置重置为 `config.json` + 环境变量的默认值（仅站长）。

> 与上游版本的差异：上游在 D1/Upstash 下禁用了站点配置、注册开关与分类管理（并要求「通过环境变量/配置文件修改」）；本版本调整了配置优先级为「数据库优先」，并解除了这些限制。

## 9. PWA

- 通过 `next-pwa`（`next.config.js`）在构建时生成 `public/sw.js` 与 `workbox-*.js`，实现离线缓存与安装到桌面。
- `public/manifest.json` 由 `scripts/generate-manifest.js` 依据 `SITE_NAME` 生成（含站点名与图标）。
